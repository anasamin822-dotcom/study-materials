RTTI & casting operators
✎ RTTI aur Casting - ekdum simple (Instinct) - video nahi mila, khud padhao+

RTTI (Run-Time Type Identification) = program chalte hue pata karna ki object asal me kis type ka hai.

Socho ek dibbe me "fruit" likha hai, andar apple ya mango kuch bhi ho sakta hai. RTTI = dibba khol ke dekhna ki andar asal me kya hai.
  • typeid(object) - object ka type batata hai. Jaise: typeid(x).name()
  • dynamic_cast - base pointer ko safely derived me convert karta hai. Galat conversion pe nullptr deta hai (crash nahi).
  • static_cast - compile time pe normal conversion (int to float jaise).
  • const_cast - const hataane/lagaane ke liye. reinterpret_cast - risky, sirf bits ko dobara padhta hai.

Exam tip: dynamic_cast sirf tab kaam karta hai jab base class me kam se kam ek virtual function ho (polymorphic class).
