Precedence (what runs first): brackets () first → power ** → multiply/divide * / // % → plus/minus + - → comparison → not → and → or last.

Just like BODMAS - brackets first, then power, then multiply-divide, then add-subtract.

Exam tip: // is floor division (drops the decimal), ** is power, and is checks identity while == checks value - these three confusions come up in every paper.

CHEAT SHEET

Last-night revision

Key formulas and facts in one list - scan it the night before the paper.

  • Immutable: int, float, str, tuple. Mutable: list, dict, set.
  • Slicing: s[start:stop:step]; s[::-1] reverses.
  • List comprehension: [x*x for x in range(10) if x%2==0]. Dict/set comprehensions work the same way.
  • Tuple vs list: tuple is faster and hashable (can be a dict key).
  • dict.get(key, default) avoids KeyError. .items() loops key + value.
  • def f(*args, **kwargs): args = tuple of positionals, kwargs = dict of named.
  • lambda x: x*2 - anonymous one-liner. map/filter/lambda often pair together.
  • File modes: 'r' read, 'w' write (truncates), 'a' append, 'r+' both. Use with open(...) as f: - auto closes.
  • try / except / else / finally - finally always runs.
  • Modules: import math, from math import sqrt. A package is a folder with __init__.py.
  • Class basics: __init__ constructor, self = the object, __str__ for print.
  • Common methods: ''.join(list), str.split(), list.append/extend, sorted(iterable, key=...).
  • range(start, stop, step) - stop is excluded.
  • Identity vs equality: 'is' checks same object, '==' checks same value.
