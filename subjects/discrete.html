✎ Special lattices - 1-minute notes (Instinct) - no video found, taught here+

Lattice = a poset in which every pair of elements has a meet (greatest common lower bound) and a join (least common upper bound).

  • Bounded lattice: has a greatest element (1) and a least element (0). Example: in the power set P(S), S is the greatest and the empty set is the least.
  • Distributive lattice: a AND (b OR c) = (a AND b) OR (a AND c) - the operation distributes both ways. The power set with union/intersection is distributive.
  • Complemented lattice: every element has a complement (x OR x' = 1, x AND x' = 0). In a power set, the complement is the set difference.

Exam tip: from the Hasse diagram, check every pair for a meet and a join. If even one pair has no meet or no join, it is NOT a lattice.

Integral domain, division ring & fields
✎ Integral Domain & Field - made simple (Instinct) - no video found, taught here+

First, a ring: a set of numbers where both + and x work nicely (like integers: 1+2=3, 2x3=6).

Zero divisor: two non-zero numbers whose product is 0. This never happens with normal integers. But in Z6 (clock numbers 0-5): 2 x 3 = 6 = 0 - so 2 and 3 are zero divisors.

Integral domain: a ring with no zero divisors. Example: Z (all integers) - here a x b = 0 only when a or b is itself 0.

Field: a ring where every non-zero number has its inverse in the same set - meaning you can divide.

Small example: in Z5 (numbers 0-4), check: 2 x 3 = 6 = 1, so the inverse of 2 is 3. And 4 x 4 = 16 = 1, so 4 is its own inverse. Every element has an inverse - Z5 is a field. Z (integers) is not a field, because the inverse of 2 is 1/2, which is not an integer.

Rule to remember: every field is an integral domain (if inverses exist, zero divisors cannot). Every finite integral domain is always a field.

CHEAT SHEET

Last-night revision

Key formulas and facts in one list - scan it the night before the paper.

  • Inclusion-Exclusion: |A ∪ B| = |A| + |B| − |A ∩ B|; for 3 sets add pairwise, subtract triple.
  • Pigeonhole: if n+1 objects go into n boxes, some box gets at least 2. Ceiling form: at least ⌈n/k⌉ per box.
  • Permutations: nPr = n!/(n−r)!  ·  Combinations: nCr = n!/(r!(n−r)!).
  • Binomial theorem: (x+y)^n = Σ nCr · x^(n−r) y^r.
  • Geometric recurrence an = an−1·r → an = a0·r^n.
  • Linear homogeneous recurrence: solve characteristic equation; distinct roots r1, r2 → an = A·r1^n + B·r2^n; repeated root r → (A + Bn)r^n.
  • Relation properties: reflexive (xRx), symmetric (xRy ⇒ yRx), transitive. Equivalence = all three.
  • POSET: reflexive + antisymmetric + transitive. Lattice: every pair has a meet and a join.
  • Group axioms: closure, associativity, identity, inverse. Abelian adds commutativity.
  • Lagrange's theorem: in a finite group, the order of every subgroup divides the order of the group.
  • Ring: abelian group under +, semigroup under ·, distributive laws. Field = commutative ring with 1 where every non-zero element has an inverse.
  • Handshaking lemma: Σdeg(v) = 2|E|. Euler circuit exists ⇔ connected and every vertex has even degree.
  • Tree with n vertices has exactly n−1 edges; exactly one path between any two vertices.
  • Kruskal / Prim: grow a minimum spanning tree by cheapest safe edge.
