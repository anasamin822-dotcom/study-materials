Barrel shifter & ALU
✎ Barrel Shifter & ALU - made simple (Instinct) - no video found, taught here+

Barrel shifter: a circuit that shifts data bits left or right by any number of positions in a single clock cycle.

Like musical chairs - everyone gets up at once and sits 2 seats ahead. The whole shift happens in one round. A normal shift register moves only 1 seat per tick; a barrel shifter moves 2, 3, 4... whatever you ask, in one tick.

How it is built: from rows of MUXes (multiplexers). Each output bit has a MUX that chooses which input bit lands there. The shift amount (how far to shift) drives the select lines of the MUXes.

ALU (Arithmetic Logic Unit): the part of a processor that does both calculation (add, subtract) and logic (AND, OR, XOR).

  • Select lines decide the operation: 00 = ADD, 01 = SUB, 10 = AND, 11 = OR (example).
  • Inside: full adders + logic gates + a MUX that picks the final answer.

Exam tip: "ALU = adder + logic gates + MUX" - write these 3 things with a diagram and the marks are yours.

Barrel Shifter: aisa circuit jo data ke bits ko ek hi clock me kitne bhi positions left/right shift kar de.

Jaise musical chairs - sab log ek saath apni seat se uth ke 2 seat aage baith gaye. Ek round me hi poora shift. Normal shift register har tick pe sirf 1 seat shift karta hai; barrel shifter ek tick me 2, 3, 4... jo bolo.

Kaise banta hai: MUX (multiplexers) ki lines se. Har output bit ke liye ek MUX jo choose karta hai ki kaunsa input bit wahan aayega. Shift amount (kitna shift karna hai) MUX ke select lines pe jaata hai.

ALU (Arithmetic Logic Unit): processor ka wo hissa jo calculation (add, subtract) aur logic (AND, OR, XOR) dono karta hai.

  • Select lines decide karti hain kaunsa operation hoga: 00 = ADD, 01 = SUB, 10 = AND, 11 = OR (example).
  • Andar: full adders + logic gates + ek MUX jo final answer chunta hai.

Exam tip: "ALU = adder + logic gates + MUX" - ye 3 cheezein likh ke diagram banao, marks pakka.

Analysis of clocked sequential circuits
State reduction & ASM charts
✎ State Reduction & ASM Charts - simple notes (Instinct) - no video found, taught here+

Why reduce states? Two states are equivalent when, for every input, they give the same output and move to equivalent next-states. Merging them gives a smaller circuit (fewer flip-flops, less hardware) that behaves identically.

State reduction - steps (row-matching / implication table):

  1. Write the full state table (present state, next state for each input, output).
  2. Find pairs of states with identical outputs and identical (or equivalent) next-states for every input.
  3. Merge each equivalent pair into one state and rewrite the table. Repeat until no pair merges.
  4. Result: the minimal state table - same behaviour, fewest states.
Like finding two apps on your phone that do the exact same job - delete one, nothing changes for you, but the phone runs lighter.

ASM chart (Algorithmic State Machine): a flowchart-style way to describe a sequential circuit. Three blocks: state box (one state, lists Moore outputs), decision box (diamond - checks an input condition, branches), conditional output box (oval - Mealy outputs that depend on state + input). Each path through state box -> decisions -> next state is one clock cycle. To design: draw the ASM chart, convert each state box to a state, read transitions and outputs straight into the state table.

Exam tip: for reduction, always show the equivalence pairs you merged; for ASM, label every box type - examiners deduct for missing state-box names.

States kam kyu karein? Do states equivalent hote hain jab har input pe wo same output dete hain aur equivalent next-states pe jaate hain. Unhe merge kar dene se circuit chhota ban jata hai (kam flip-flops, kam hardware) par behaviour bilkul same rehta hai.

State reduction ke steps (row-matching / implication table):

  1. Poori state table likho (present state, har input ka next state, output).
  2. Aise pairs dhundo jinke outputs same ho aur har input pe next-states bhi same (ya equivalent) ho.
  3. Har equivalent pair ko ek state me merge karo aur table dobara likho. Tab tak repeat karo jab tak koi pair merge na ho.
  4. Result: minimal state table - behaviour same, states sabse kam.
Jaise phone pe do apps jo exactly same kaam karte hon - ek delete kar do, kaam waisa hi chalega.

ASM chart = state machine ka flowchart: state box (rectangle, ek state + uske outputs), decision box (diamond, input check), conditional output box (oval, Mealy outputs jo input pe depend karte hain). Har path ek clock cycle batata hai.

Pulse train generator & PRBS generator
✎ Pulse Train & PRBS Generator - made simple (Instinct) - no video found, taught here+

Pulse train generator = a circuit that outputs a fixed pattern on every clock tick, again and again. Example: 1, 0, 1, 1, 0 ... then back to 1, 0, 1, 1, 0 ... repeat.

Imagine people standing in a line. On every "tick", everyone steps forward and the person at the end of the line steps out. The pattern that comes out is the pulse train.

How to build it: a shift register (a line of flip-flops) plus a feedback wire that decides what goes back into the start of the line.

Small example: want the pattern 101 (length 3). Take 3 flip-flops: Q1 Q2 Q3. On every tick all bits shift forward and the feedback puts the right new bit at the start. The pattern repeats forever: 101, 101, 101...

Clock generation: a T flip-flop halves the input frequency. This is how a slow, steady clock is made from a crystal oscillator.

PRBS (Pseudo-Random Binary Sequence): a magic box that gives "random-looking" bits - but actually from a fixed rule, so it is pseudo (fake) random.

How it is built: some middle outputs of the shift register are XORed and fed back. This is called an LFSR (Linear Feedback Shift Register). With n flip-flops you can get a maximum-length sequence of 2^n - 1 bits before it repeats.

Where used: testing communication links, noise generation, bit-error-rate testing.

Exam tip: draw the shift register, mark the XOR feedback taps, and trace 4-5 clock cycles in a table - that is the standard full-marks answer.

Pulse Train Generator = aisa circuit jo har clock tick pe ek fixed pattern deta hai, baar-baar. Jaise: 1, 0, 1, 1, 0 ... phir wapas 1, 0, 1, 1, 0 ... repeat.

Socho ek line me log khade hain. Har "tick" pe sab ek kadam aage badhte hain, aur jo aadmi line ke end pe hai woh bahar nikal jata hai. Jo pattern bahar aata hai, wahi pulse train hai.

Kaise banate hain: Shift register (flip-flops ki line) + ek feedback wire jo decide karti hai ki line ke start me kya wapas daalna hai.

Chhota example: Pattern 101 chahiye (length 3). 3 flip-flops lo: Q1 Q2 Q3. Har tick pe sab aage shift hote hain, feedback se start me naya bit aata hai. Pattern baar-baar aata rahega: 101, 101, 101...

Clock generation: Ek T flip-flop input frequency ko half kar deta hai. Aise crystal oscillator se slow, steady clock banti hai.

PRBS (Pseudo-Random Binary Sequence): Ek magic box jo "random" jaisi numbers deta hai - par asal me fixed rule se, isliye pseudo (naqli) random.

Kaise banta hai: Shift register me beech ke kuch outputs ka XOR karke feedback daalte hain. Ise LFSR kehte hain. n flip-flops ho to 2^n - 1 alag states aati hain, phir repeat. (All-zero state allowed nahi, warna circuit wahi atak jayega.)

Chhota example: 3 flip-flops, feedback = Q3 XOR Q1, start 111: 111 → 011 → 101 → 010 → 001 → 100 → 110 → wapas 111. Total 7 states (2^3 - 1 = 7), phir repeat. Yehi PRBS hai.

CHEAT SHEET

Last-night revision

Key formulas and facts in one list - scan it the night before the paper.

  • De Morgan: (A·B)' = A' + B' and (A + B)' = A'·B'.
  • Basic laws: A + AB = A; A + A'B = A + B; A·(A + B) = A.
  • SOP = sum of minterms; POS = product of maxterms. K-map groups 1s in powers of 2 for minimal SOP.
  • NAND and NOR are universal gates - any circuit can be built from either alone.
  • Half adder: Sum = A⊕B, Carry = A·B. Full adder: Sum = A⊕B⊕Cin, Cout = AB + Cin(A⊕B).
  • Multiplexer 2^n:1 has n select lines. Decoder n→2^n. Encoder is the reverse.
  • SR flip-flop: S=1 sets, R=1 resets, S=R=1 invalid. JK removes the invalid state (toggles on J=K=1).
  • Characteristic equations: D: Q+ = D  ·  T: Q+ = T⊕Q  ·  JK: Q+ = JQ' + K'Q.
  • Mod-N counter needs ⌈log2 N⌉ flip-flops. Ripple = async, each FF clocks the next.
  • Shift registers: SISO, SIPO, PISO, PIPO - used to store and move data serially/parallel.
  • FSM: Mealy output depends on state + input; Moore output depends on state only.
  • TTL: fast, bipolar, more power. CMOS: low power, high density, slower static - most common today.
  • Memory: ROM (non-volatile), SRAM (fast, no refresh), DRAM (dense, needs refresh).
  • VHDL: entity = interface (ports), architecture = behaviour. Process blocks run concurrently.
