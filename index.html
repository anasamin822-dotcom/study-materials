QUESTION OF THE DAY

One exam question, every day

A new question rotates in each day - try it before you open the answer.

❓ Prove that the relation 'x - y is divisible by 3' on the set of integers is an equivalence relation. [CST-002]+
Reflexive: x - x = 0 = 3x0, divisible by 3. Symmetric: if 3 | (x-y) then x-y = 3k, so y-x = 3(-k), also divisible. Transitive: if x-y = 3a and y-z = 3b then x-z = 3(a+b). All three hold, so it is an equivalence relation.
❓ State the handshaking lemma and use it to show that a graph cannot have exactly 3 vertices of odd degree. [CST-002]+
Handshaking lemma: sum of all vertex degrees = 2 x (number of edges), an even number. The sum of even-degree vertices is even, so the sum over odd-degree vertices must also be even - which needs an EVEN count of odd-degree vertices. 3 is odd, so impossible.
❓ Solve the recurrence a(n) = 5a(n-1) - 6a(n-2), with a(0) = 2, a(1) = 5. [CST-002]+
Characteristic equation r^2 - 5r + 6 = 0 gives r = 2, 3. General solution a(n) = A.2^n + B.3^n. From a(0): A + B = 2; from a(1): 2A + 3B = 5. Solving: A = 1, B = 1. So a(n) = 2^n + 3^n.
❓ Every lattice is a poset, but is every poset a lattice? Justify. [CST-002]+
No. A lattice needs EVERY pair of elements to have a least upper bound (join) and greatest lower bound (meet). Counter-example: the poset {a, b, c, d} with a,b below both c,d but a,b incomparable - c and d have no unique meet below... precisely: two incomparable elements may lack a join or meet, so such a poset is not a lattice.
❓ Convert the infix expression A + B * C to postfix, showing the stack at each step. [CST-003]+
Read A -> output A. '+' -> push. Read B -> output AB. '*' has higher precedence than '+' -> push. Read C -> output ABC. End: pop '*' then '+'. Postfix: A B C * +.
❓ Why is binary search O(log n) and what is its one strict requirement? [CST-003]+
Each comparison halves the search range, so n -> n/2 -> n/4 ... reaches 1 in log2(n) steps. Requirement: the array must be sorted (and support random access).
❓ What is the difference between a stack and a queue? Give one application of each. [CST-003]+
Stack is LIFO (push/pop at the same end - application: function-call stack or undo). Queue is FIFO (insert at rear, delete at front - application: printer job scheduling or BFS).
❓ Show the order of visited nodes in BFS and DFS starting from the root of any 3-level binary tree. Which data structure does each use? [CST-003]+
BFS visits level by level: root, then level-1 left-to-right, then level-2 left-to-right - uses a QUEUE. DFS dives down a branch to a leaf, backtracks, then takes the next branch - uses a STACK (or recursion).
❓ What is a copy constructor and when is it called? Give one example. [CST-004]+
A constructor that initialises a new object from an existing one: Complex(const Complex &c). Called when an object is initialised from another object, passed by value, or returned by value. Example: Complex c2 = c1;
❓ Predict the order of constructor and destructor calls for: class B derived from class A, object of B created in main. [CST-004]+
Construction: base class A's constructor runs first, then derived B's. Destruction is the reverse: B's destructor, then A's.
❓ What is the difference between overloading and overriding? [CST-004]+
Overloading: same function name, different parameter lists, same class - resolved at COMPILE time. Overriding: same signature, one in base and one in derived class - resolved at RUN time (with virtual).
❓ Why is a virtual base class used in multiple inheritance? [CST-004]+
To fix the diamond problem: when two paths lead to the same grandparent class, a normal inheritance gives two copies of its data. Declaring the grandparent 'virtual' ensures only ONE shared copy exists, removing ambiguity.
❓ Minimise using a 3-variable K-map: F(A,B,C) = Sum of m(0, 2, 4, 6). [ECT-033]+
All minterms have C = 0. Group all four 1s into one quad: every cell in the group has C' constant while A and B change, so they drop out. F = C'.
❓ Design a full adder using two half adders and one OR gate - give the equations. [ECT-033]+
First half adder: S1 = A xor B, C1 = AB. Second: Sum = S1 xor Cin, C2 = S1.Cin. Final: Carry = C1 + C2 (OR gate). Sum = A xor B xor Cin, Carry = AB + BCin + ACin.
❓ Compare ripple (asynchronous) and synchronous counters. [ECT-033]+
Ripple: flip-flops clocked by the previous output - simple but slow (delays add up) and has glitches. Synchronous: all flip-flops share one clock - faster, no cumulative delay, needs more logic. Synchronous is preferred for high speed.
❓ Implement F(A,B,C) = Sum m(1,3,5,7) using an 8:1 MUX. [ECT-033]+
Connect A,B,C to the select lines S2,S1,S0. Data input Di = 1 exactly where i is in {1,3,5,7}, else 0: D0=0, D1=1, D2=0, D3=1, D4=0, D5=1, D6=0, D7=1. (F = C, so equally all odd data lines are 1.)
❓ What is the output of: print(type(7/2), type(7//2), 2**3)? [CST-005]+
7/2 = 3.5 so float; 7//2 = 3 (floor division) so int; 2**3 = 8. Output: <class 'float'> <class 'int'> 8
❓ What is the difference between a list and a tuple? When do you prefer a tuple? [CST-005]+
List is mutable (can change after creation); tuple is immutable. Prefer a tuple for fixed records, as dictionary keys, or when data must not change - tuples are also faster and use less memory.
❓ Write a one-line list comprehension for squares of even numbers from 0 to 19. [CST-005]+
[x*x for x in range(20) if x % 2 == 0] -> [0, 4, 16, 36, 64, 100, 144, 196, 256, 324]
❓ What does 'with open(...) as f:' buy you over plain open()? [CST-005]+
Automatic cleanup: the file is closed for you even if an exception happens inside the block - no leaked file handles and no forgotten close() calls.
❓ List the nine feelings (values) in relationship. Which two are explained as the foundation and the base of evaluation? [AHT-008]+
Trust, respect, affection, care, guidance, reverence, glory, gratitude, love. Trust (vishwas) is the FOUNDATION value; respect (sammaan) is right evaluation - seeing that the other is similar to me.
❓ Differentiate the needs of the Self (I) and the Body. [AHT-008]+
Self needs are continuous and qualitative - happiness through feelings like trust and respect. Body needs are temporary and quantitative - physical facilities like food and shelter, needed in limited amounts. Mixing them up (seeking continuous happiness from facilities) causes dissatisfaction.
❓ Name the four orders of nature and the innateness (svabhava) of each. [AHT-008]+
Material order (existence), pranic/plant order (existence + growth), animal order (existence, growth + will to live), human order (all of these + will to live with happiness / knowledge). The first three are naturally in harmony; humans must understand to participate.
❓ What is self-exploration (svatva)? Name its two steps. [AHT-008]+
A process of dialogue within yourself - between 'what I am' and 'what I really want to be' (my natural acceptance). You verify each proposal on your own right, in your own living, instead of accepting or rejecting it blindly; what survives verification becomes your own understanding and you live by it.
❓ Verify Rolle's theorem for f(x) = x^2 - 4 on [-2, 2]. [AHT-003]+
f is a polynomial: continuous on [-2,2], differentiable on (-2,2). f(-2) = f(2) = 0, so end values match. f'(x) = 2x = 0 at x = 0, and 0 lies in (-2,2). All conditions satisfied - Rolle's theorem verified with c = 0.
❓ State the relationship between Beta and Gamma functions and evaluate Gamma(7/2). [AHT-003]+
B(m,n) = Gamma(m)Gamma(n)/Gamma(m+n). Gamma(7/2) = (5/2)(3/2)(1/2)Gamma(1/2) = (15/8) x sqrt(pi) = 15 sqrt(pi) / 8, using Gamma(n+1) = n.Gamma(n) and Gamma(1/2) = sqrt(pi).
❓ If eigen values of a 3x3 matrix A are 1, 2, 3, find the eigen values of A^2 and the determinant of A. [AHT-003]+
Eigen values of A^2 are the squares: 1, 4, 9. Determinant = product of eigen values = 1 x 2 x 3 = 6. (Also trace = 1+2+3 = 6.)
❓ What is the geometrical meaning of the gradient of a scalar function? [AHT-003]+
grad(phi) is a vector pointing in the direction of the FASTEST increase of phi; its magnitude equals that maximum rate of change. The directional derivative in any direction is grad(phi) dot the unit vector in that direction.
❓ Using MOT, find the bond order of O2 and state whether it is paramagnetic or diamagnetic. [AHT-002]+
O2 has 16 electrons. Filling the MOs: (sigma1s)^2 (sigma*1s)^2 (sigma2s)^2 (sigma*2s)^2 (sigma2pz)^2 (pi2p)^4 (pi*2p)^2. Bond order = (10 - 6)/2 = 2. The two pi* electrons occupy separate orbitals with parallel spins (Hund's rule) - so O2 is PARAMAGNETIC.
❓ State the Nernst equation for a single electrode at 25 C and calculate E for a Zn2+/Zn electrode, E0 = -0.76 V, [Zn2+] = 0.1 M. [AHT-002]+
E = E0 - (0.0591/n) log(1/[Mn+]) = E0 + (0.0591/n) log[Mn+]. For Zn, n = 2: E = -0.76 + (0.0591/2) log(0.1) = -0.76 + 0.0296 x (-1) = -0.7896 V, about -0.79 V.
❓ Distinguish temporary and permanent hardness of water, with one removal method for each. [AHT-002]+
Temporary: caused by bicarbonates of Ca/Mg, removed by BOILING (or Clark's method - adding lime). Permanent: caused by chlorides/sulphates of Ca/Mg, NOT removed by boiling - needs lime-soda, zeolite, or ion-exchange treatment.
❓ Write the synthesis of aspirin with the reagents and the type of reaction. [AHT-002]+
Salicylic acid is heated with acetic anhydride (a drop of conc. H2SO4 as catalyst): the -OH group of salicylic acid is acetylated to -OCOCH3, giving acetylsalicylic acid (aspirin). Reaction type: esterification (acetylation).
