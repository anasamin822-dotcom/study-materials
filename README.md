Ek hi website, har subject ka alag section - poora syllabus unit-wise (Unit 1 se Unit 5). Har topic ke saath **verified YouTube videos** (first preference), aur jahan video nahi mila wahan **ekdum simple Hinglish notes** (khud likhe hue, chhote examples ke saath).

## Features

- 440+ hand-verified YouTube video links (playlist + exact video numbers checked via yt-dlp)
- Progress tracking (tick videos you watched, saved in localStorage)
- Self-taught notes for gap topics (simple Hinglish, analogies, tiny examples)
- Mobile-first, `prefers-reduced-motion` respected, zero frameworks, zero cost

## UI/UX inspiration (21 sites, standing rule)

- **Aceternity UI**: spotlight hero, dot-grid background, 3D tilt cards, floating pill navbar
- **Skiper UI**: card-stack / sticky card ideas (free components, attribution in code)
- **Scrolltide**: scroll-driven reveal animations
- **Supahero**: big-type hero sections
- **Navbar Gallery**: floating pill nav pattern
- **Footer.design**: giant outline footer type (ANAS)
- **CTA Gallery**: pill CTAs with arrow hover
- **hoverstat.es**: link/button hover states
- **darkmodedesign**: dark palettes
- **fontsinuse**: Space Grotesk + Inter + JetBrains Mono pairing
- **onepagelove / lapa.ninja / land-book / landing.love**: landing structure (hero -> sections -> CTA -> footer)
- **minimal.gallery / httpster / siteinspire / designmadeingermany**: typography + grid discipline on light pages (OOP, Python, UHV)
- **bestwebsite.gallery**: marquee strip, big number badges
- **Refero Styles**: per-subject style switch (neo-brutalist, glass, terminal, editorial, minimal)
- **componentry.dev**: animated accordions for self-taught notes
- **3D Icons**: chunky gradient icon badges on subject cards
- (Animmaster Lib: inspiration only - paid, so look-alikes rebuilt in vanilla CSS/JS)

## Stack

Plain HTML + CSS + JS. No build step, no dependencies. Generated by a small Python script (`src/build.py`) from content data (`src/content_*.py`); video links verified against live playlist data.

## Security

Static site - no forms, no backend, no cookies, no trackers, no inline secrets. Checked with the standing repo-tooling rules (see commit history).
